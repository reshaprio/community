## Introduction

This repository is a space for discussing and debating various aspects of running the reShapr organization, how we function as a community, and our shared inspirations and expectations.

## Discussions and Discord

Reach out with any questions you may have, and we'll make sure to answer them as soon as possible. As a community member, feel free to jump in and answer questions too.

reShapr uses Discord and GitHub Issues to facilitate our communications, each serving a different purpose.

Discord is the go-to for lively conversations, announcements, support, and real-time community assistance. For anything that needs a durable, searchable record — feature proposals, bug reports, longer-running discussions — we use GitHub Issues on the relevant repository (starting with [reshaprio/reshapr](https://github.com/reshaprio/reshapr/issues)).

| Platform | Link |
|:---------|:-----|
| 💬 Discord (preferred) | https://discord.gg/KyDUdam34h |
| 🐛 Issues | https://github.com/reshaprio/reshapr/issues |

## Community meetings

We don't have a regular open community meeting cadence yet — we're still a young community. We plan to establish one (open, recurring, recorded) as the project and contributor base grow.

In the meantime, the best way to reach us in real time is [Discord](https://discord.gg/KyDUdam34h).

## Getting involved

reShapr is a community that lives on its contributors. As we grow, we need more people to help others. Do you want to get involved? You can contribute in many ways!

Please check out our [Contribution guidelines](https://github.com/reshaprio/.github/blob/main/CONTRIBUTING.md) to learn more.

## Community contributions

> 🚀 **Community-Driven Effort**
> The [`community-contributions/`](./community-contributions) directory is maintained by **community contributors**, not the core reShapr maintainers.
> It hosts guides, tools, and integrations that are useful to the reShapr ecosystem but out of scope for the core project itself.

This is where community members document and share things the core maintainers don't own or promise to maintain, such as:

- **[Install](./community-contributions/install)** — deploying reShapr on specific cloud providers or platforms (e.g. EKS, GKE, AKS).
- **[Tools](./community-contributions/tools)** — third-party tooling, scripts, and utilities built around reShapr.
- **[Integrations](./community-contributions/integrations)** — recipes for connecting reShapr to specific LLM providers or MCP clients.

These directories start empty on purpose — see each one's README for how to contribute a guide. If your platform, tool, or integration isn't listed yet, open an issue or a pull request.
