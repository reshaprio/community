# AAIF

This directory is dedicated to sharing **[Agentic AI Foundation (AAIF)](https://aaif.io/)-related activities, materials, and resources** for the reShapr project.

## Purpose

reShapr intends to donate the project to AAIF so it can evolve under open governance, with transparency and long-term sustainability — the same role the Cloud Native Computing Foundation (CNCF) plays for many other open source projects.

The goal of this directory is to share with the community the work the maintainers are doing towards that goal: aligning reShapr with AAIF's expectations, processes, and best practices, starting with our target of the **AAIF Sandbox**.

## What you will find here

This directory aims to:

- Make visible the background work done by maintainers related to AAIF engagement.
- Centralize documents and resources useful for adopters and contributors (for example: applications and onboarding materials).
- Provide a welcoming place for community members to contribute ideas, feedback, and improvements.
- Enable collaborative maintenance of resources to keep them accurate and up to date.

## Structure

- [`sandbox/`](./sandbox) — materials related to our AAIF Sandbox application.

## Community-driven

The intent is to keep this content **open, transparent, and community-driven**.
Contributions, suggestions, and feedback are welcome and encouraged.
