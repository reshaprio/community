# reShapr Community Contributions

> 🚀 **Community-Driven Effort**
> This directory is maintained by **community contributors**, not the core reShapr maintainers.
> It hosts guides, tools, and integrations that are useful to the reShapr ecosystem but out of scope for the core project.

## What goes here

| Folder | What it's for |
|:-------|:---------------|
| [`install/`](./install) | Deploying reShapr on a specific cloud provider or platform (e.g. EKS, GKE, AKS) |
| [`tools/`](./tools) | Third-party tooling, scripts, and utilities built around reShapr |
| [`integrations/`](./integrations) | Recipes for connecting reShapr to specific LLM providers or MCP clients |

## Contributing a guide

1. Pick the folder that fits (or open an issue if none do).
2. Add a subfolder named after your platform/tool/integration, with its own `README.md`.
3. Open a pull request. It'll be reviewed by the community, not gated on core maintainer bandwidth.

None of this is officially supported by the reShapr maintainers — treat it as community best-effort, and say so in your guide.
