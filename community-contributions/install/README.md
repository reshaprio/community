# reShapr Deployment Guides

> 🚀 **Community-Driven Deployment Effort**
> This section is maintained by **community contributors**, not the core reShapr maintainers.
> These guides aim to provide best practices for deploying reShapr on various cloud providers and platforms.

## Overview

reShapr runs anywhere a container or a JVM can, so it fits naturally into managed Kubernetes services and other cloud platforms. This folder collects deployment guides contributed by the community for specific providers.

| Platform | Status |
|:---------|:-------|
| _None yet_ | [Looking for contributions](https://github.com/reshaprio/community/issues) |

Don't see your platform listed? [Open an issue](https://github.com/reshaprio/community/issues) or contribute a guide directly.

## Contributing a guide

Add a subfolder here named after the platform (e.g. `aws/`, `gcp/`, `azure/`) with a `README.md` covering prerequisites, steps, and any gotchas specific to that platform.
