# reShapr Integrations

> 🚀 **Community-Driven Effort**
> This section is maintained by **community contributors**, not the core reShapr maintainers.

This folder collects community-contributed recipes for connecting reShapr to specific LLM providers, MCP clients, or other tools in the AI-native API stack.

## Contributing

Add a subfolder here named after the provider/client (e.g. `claude-desktop/`, `cursor/`, `bedrock/`) with a `README.md` walking through the setup.
