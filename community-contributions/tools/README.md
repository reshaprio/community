# reShapr Tooling

> 🚀 **Community-Driven Effort**
> This section is maintained by **community contributors**, not the core reShapr maintainers.

This folder is dedicated to community contributions related to tooling built around reShapr — scripts, CLI helpers, editor plugins, dashboards, or anything else that makes reShapr easier to run or operate.

## Contributing

Add a subfolder here named after your tool, with a `README.md` explaining what it does and how to use it.
